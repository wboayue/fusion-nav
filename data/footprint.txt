# What the filter costs a bare-metal target, pinned exactly; `tools/footprint.sh` measures and
# compares, in CI. One line per kind of figure; a target's lines are read as one.
#
#   <target> key=value ...
#
# `size.` is a type's bytes, `frame.` a function's stack frame at `opt-level = 3`, `text.` and
# `rodata.` the flash of `panic-check`'s ELF at each opt-level, `text_<crate>.` what that crate
# kept out of line. `tools/footprint.py` says what each key means and leaves out; a `frame.` of
# a generic function is its largest instance, so a chain summed from these keys is a bound.
# DESIGN.md, "Measured cost, by function", quotes them and says which forms they decided.
#
# Exact, on the nightly the script pins, so any move fails, growth or shrinkage: a figure that
# moves is a diff to explain, and DESIGN.md's quotes move with it. `tools/footprint.sh --pin`
# prints these lines at the measured values. Moving the nightly is a re-pin of its own.
#

# frames that stack on it (a frame is one function's, so the crate's high-water mark,
# `fuse_gnss_velocity` into `update.update.3`, is a sum DESIGN.md takes); each `fuse_*`;
# propagation and the arming query; the starts. `--all` lists every function measured.
