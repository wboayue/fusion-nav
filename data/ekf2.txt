# `tools/replay_report.py --corpus` prints. Regenerate with
# `data/fetch.sh --compare --pin`. Local only, like `--check`: it needs the
# fetched logs, pyulog and uv. data/README.md, "Agreement with EKF2", owns what
# each key means and what it cannot say.
#
# EKF2 is not truth. Every key is a distance between two estimators fed one log,
# so a line here pins agreement, and moving one needs a sentence saying which
# filter moved and why, never that it got "better".
#
# Two policies per log. `raw` is the one data/manifest.txt pins, every receiver
# variance fused as reported; `--pin` leaves out of a raw line every key the
# log's manifest entry already pins (`nis_`, `rejected_`, `resets=`, ...). `px4` fuses GNSS at EKF2's own
# floors, with the parameters the log flew (`# GNSS noise parameters` in the
# converted header), so its distance from EKF2 has one R policy in it rather
# than two; its harness keys are pinned here because nothing else pins them.
#
# Statistics are pinned as the value +/- the larger of 1 % and one printed unit,
# the rule data/manifest.txt states. `tools/agreement.py` prints every statistic
# to four figures with a decimal point and every count without one, and that
# point is what `pin_pairs --decimal` bands; counts, words, zeros and `none`
# are pinned exactly. A
