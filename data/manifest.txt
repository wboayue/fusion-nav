# sha256  name  url  [expectations]
#
# Expectations are `key=value` pairs matched against the `summary` line that
# `cargo run --example replay` prints, and checked by `data/fetch.sh --check`.
# They are what makes "the only log that exercises StepTooLong" a claim the build
# enforces rather than a comment that quietly goes stale.
#
# heading= is Validity::heading as initialization left it, not as the log
# ended. Only a magnetometer observes the rotation about gravity, and the
# covariance cannot say so on its own -- Initialization::sigma_yaw and
# Accuracy::heading are the same 0.35 rad, so a yaw nobody measured passes the
# bar exactly. Every log here carries a magnetometer in its window, so every
# static one is valid; the key is what would notice if one stopped. Taking it
# at the end of the log instead would say only that some heading was fused at
# some point, which transitions= already notices.
#
# aligned_at= is seconds from the end of the initialization window to the
# first epoch whose Validity::attitude read true, or never. It is what would
# settle Accuracy's attitude defaults off the corpus the way replay settled
# Timeouts::degraded_after: tilt equals Initialization::sigma_tilt and
# heading equals sigma_yaw, compared with <=, so a static start passes by
# exactly zero margin and every static log here reads 0.00.
#
# 2c42096b reads never, and not for want of a magnetometer -- it logs 35631
# of them. A coarse start's attitude prior is wider than Accuracy allows,
# and the stub shrinks no covariance, so neither tilt nor heading ever comes
# back under the bar. Both halves of that move when #35 lands: this key
# measures the stub until covariance propagation is real, which is the
# reason to pin it now rather than after.
#
# rejected= is the gate's verdict and discarded= is everything that never
# reached it -- a variance of zero or less, a NaN, an altitude with no
# reference. Nothing on this line reported either before: refused= and
# invalid= count propagation steps, not measurements, so a change that began
# turning down every fix in the corpus would have passed --check unmoved.
# rejected= is zero everywhere until the chi-square gate of (37) is real, and
# is pinned now so the first non-zero is a diff rather than a discovery.
#
# discarded= is also what separates two logs that alpha0= reads the same way.
# 7592c9b2 is alpha0=none discarded=0: an LPE log with no barometer rows at
# all. 2c42096b is alpha0=none discarded=35575: a barometer that reports
# throughout, every row of it thrown away for want of a reference a moving
# window could not establish. Counted after the commit, because Diagnostics
# resets there -- what a log refuses before it initializes is the harness's
# startup order and not the flight.
#
# an= is a_n of equation (5'), the vehicle's own acceleration over the window,
# and says only whether one was measured. Only a start the filter classified as
# moving reports one, so an=none covers both "the start was static" and "no two
# samples in the window carried a GNSS velocity" -- which is why it is pinned per
# log rather than read as a property of the data.
#
# roll0=, pitch0= and yaw0= are the attitude of equations (5)-(7), in degrees,
# taken at initialization rather than at the end of the log for the reason
# heading= is. They are the only keys here that look at attitude at all, and
# what they would catch is a sign inverted in the down-positive convention, the
# levelling dropped out of (6), or a declination that stopped reaching the
# filter. A window carrying no magnetometer has nothing to observe yaw with, so
# yaw0=0.00 there and heading= says which case it is. Two decimals, rounded
# before printing so that an angle just below zero cannot print as -0.00 and
# read as a moved expectation.
#
# PX4 Flight Review public logs are CC BY 4.0, so a corpus can be pinned here and
# redistributed with attribution. The files themselves stay out of the repo
# (data/logs/ is gitignored); this manifest is what makes the corpus reproducible.
#
# To add one, fetch it once and commit the line the script appends:
#
#   data/fetch.sh --add 'https://cdn.logs.px4.io/<log-id>.ulg'
#
# Browse https://review.px4.io/ for a flight with GNSS, barometer and magnetometer
# active; https://review.px4.io/dbinfo is the same database as JSON, with a
# download_url per entry. Then:
#
#   uv run tools/ulog2replay.py data/logs/<log-id>.ulg -o data/logs/<log-id>.csv --reference
#   cargo run --example replay -- data/logs/<log-id>.csv
#
# Everyone else afterwards runs `data/fetch.sh`, which verifies against the
# checksums below.

# a 105 MB CSV. What nothing else in the corpus covers:
#   - Duration. At 7127 s an f32 timestamp has a 0.49 ms ULP, so a 5 ms step
#     reads as 5.371 ms; this is the regression guard for parsing t_s as f64.
#   - vehicle_gps_position as the topic, rather than sensor_gps.
#   - 443 real GNSS outages longer than 2.5 s, longest 8.0 s, while the
#     barometer has none -- the logger was fine and the GNSS genuinely
#     stopped. The only true sensor dropout in the corpus.
#   - The only log that starts in motion: peak |a|-g of 5.5 m/s^2 over the
#     first eligible window, so it is the one entry that exercises a coarse
#     start, Status::Aligning, and the two Fusion::Reset adoptions that
#     give a moving start its first position and velocity. A coarse start
#     establishes no barometric reference, so alpha0=none here and its
#     35575 barometer rows are all refused with Fusion::NoReference --
#     the application would have to name a reference. That is the whole
#     reason the alpha0 key exists: nothing else in the summary line
#     notices barometric aiding disappearing. It is also the one entry with
#     heading=invalid: its window carries a magnetometer, so yaw0 is a
#     computed -22.47 rather than zero, but a coarse start has levelled it
#     against a tilt nothing vouches for -- yaw starts at the full circle and
#     Unestablished::heading says nothing has established it. Expect this
#     to change when equations (34)-(36) land and the yaw reset it
#     describes is performed.
#   - The only entry with an=measured: its window carries two GNSS
#     velocity rows, 1 s apart, so the vehicle's own acceleration is
#     measurable and equation (5') has something to subtract. What it
#     measures says the subtraction is not worth making here. a_n is
#     0.14 m/s^2 while the receiver reports sigma_v = 0.28 m/s, and
#     differencing two of those over 1 s is worth 0.39 m/s^2 -- the
#     number is noise. The window is a vehicle vibrating in place, not
#     translating: |a|-g peaks at 5.46 m/s^2, but roll0=0.42 and
#     pitch0=-0.89 put the *averaged* specific force just under 1 deg

#     corpus, and the tilt this window would support is nowhere near
#     the 31.9 deg (5.46/g) that attitude_sigmas charges it. roll0 and

#     cannot: the window they describe is the one the harness commits,
#     and no hand derivation over some other offset agrees with it.
#     an= is pinned to catch the velocity disappearing out of the
#     window -- a converter or window-policy change would otherwise
#     silently leave (5') nothing to work with.
